Набір для сквішів «Хом'як, Кролик, Лапка» — чудова ідея для домашнього творчого вечора або незвичайного подарунка на день народження. Усі матеріали зібрані разом, тож починати можна одразу — без зайвих покупок і підготовки.

Що можна зробити

Працюючи з силіконовим гелем A+B, Ви власноруч виллєте три різних м'яких антистрес-сквіші — хом'ячка, кролика та лапку. Техніка проста: відміряти обидва компоненти, ретельно перемішати до однорідної маси, додати барвник потрібного кольору та залити у форму. Після застигання сквіш легко виймається завдяки вазеліну, а потім оздоблюється флок-пудрою і декоративними вушками. Готові вироби приємно стискати в долонях — вони знімають напругу і стають яскравими аксесуарами або ексклюзивним подарунком ручної роботи для друзів чи близьких.

Що всередині

  • Силіконовий гель A+B (по 150 мл.) — основний матеріал: два компоненти змішуються у рівних частинах і застигають у м'яку еластичну масу.
  • Мірні стаканчики (2 шт.) — для точного відмірювання обох компонентів гелю.
  • Стаканчики для змішування (10 шт.) — одноразові ємності для замішування гелю з барвниками.
  • Палички для розмішування (5 шт.) — рівномірно перемішати компоненти до однорідного кольору та консистенції.
  • Пипетки (3 шт.) — для точного й охайного дозування барвників без зайвого бруду.
  • Барвники (5 кольорів) — надають сквішам яскравих або ніжних відтінків на Ваш смак.
  • Форми (3 шт.) — силіконові форми у вигляді хом'ячка, кролика та лапки.
  • Пензлик (1 шт.) — для нанесення вазеліну на форму та декорування поверхні сквіша.
  • Помпони (5 гр.) — пухнасті кульки для текстурного декору готового виробу.
  • Декоративні вушка (10 шт.) — пластикові деталі для оформлення персонажів.
  • Флок-пудра (10 гр.) — надає поверхні сквіша оксамитову фактуру і приємне тактильне відчуття.
  • Одноразові рукавички (2 пари) — захищають руки під час роботи з гелем і барвниками.
  • Пакети із застібкою (14 шт.) — для зберігання готових виробів і залишків матеріалу.
  • Пластикова тація (1 шт.) — підставка для роботи, яка захищає поверхню столу від забруднення.
  • Додаткові аксесуари (10 шт.) — дрібні деталі для персоналізації кожного сквіша.
  • Вазелін для змащування форм (1 шт.) — полегшує виймання застиглого виробу без деформації.
  • Покрокова інструкція (1 шт.) — наочний гід для впевненого старту навіть без попереднього досвіду.

Ідеально для

Набір розрахований на дітей від 8 років і підлітків, які хочуть уперше спробувати роботу з силіконовим гелем. Чудово підійде для домашнього хобі, сімейного дозвілля або як готовий подарунок на свято — комплект повний, треба лише розпакувати й творити.
