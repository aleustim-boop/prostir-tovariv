Хочете навчитися робити свічки своїми руками і оформлювати їх як справжні дизайнерські подарунки? Набір для виготовлення насипних свічок із парафіну — все необхідне в одному комплекті, щоб від першого разу вийшло красиво.

Результат вашої роботи

Ви отримаєте 6 насипних парафінових свічок з перламутровим мерехтінням у скляних банках. Техніка виготовлення насипних свічок в домашніх умовах проста: гранули парафіну змішуються з пігментом у пластиковому стаканчику, потім насипаються у банку з готовим гнотом — жодного розтоплювання воску, жодного спеціального обладнання. Результат — свічки своїми руками без досвіду та витрат на курси. Кожен виріб оформлюється крафтовою біркою, атласною стрічкою та мішечком з органзи — виходить подарунок, який не соромно вручити.

Склад набору

  • Парафін (1 кг) — основа для насипних свічок у форматі гранул для рівномірного наповнення банок.
  • Банки для свічок (6 шт.) — скляні банки з кришками для формування свічок.
  • Перламутрові пігменти (6 шт. по 2,8 г) — 6 кольорів для красивого мерехтливого перламутрового ефекту.
  • Гноти (6 шт.) — армовані фітілі для стабільного горіння у парафінових свічках.
  • Тримач для центрування гнотів (2 шт.) — для точного розміщення фітіля посередині банки.
  • Пакувальні мішечки (6 шт.) — мішечки з органзи для красивого пакування готових свічок.
  • Шпагат (2 м.) — для прикраси та оформлення свічок і крафтових бірок.
  • Стрічка атласна (2 м.) — для елегантного декорування свічок у подарунок.
  • Бірки крафтові (6 шт.) — для підпису кольору, аромату або особистих побажань.
  • Наліпки на банки (6 шт.) — декоративні стікери для прикраси готових виробів.
  • Стакани одноразові (6 шт.) — для змішування гранул парафіну з пігментом перед наповненням банки.
  • Палички дерев'яні (10 шт.) — для перемішування пігменту та рівномірного розподілу кольору.
  • Інструкція — покрокова інструкція зі створення насипних свічок із парафіну.

Для кого цей набір

Набір підходить дорослим і підліткам від 14 років без досвіду у свічкарстві. Готовий стартовий комплект для нового хобі, цікаве заняття на вечір у компанії або продуманий подарунок тим, хто цінує творчість і речі, зроблені власноруч.

Замовляйте набір і вже сьогодні починайте виготовляти перші насипні свічки з парафіну — для себе або в подарунок близьким. ✨
