Хочете навчитися виготовляти прикраси власноруч, але не знаєте, з чого почати? Цей набір з UV смолою та LED лампою дає Вам усе необхідне з першого дня — від форм і смоли до готової фурнітури для брелоків, сережок і кулонів.

Що можна зробити

Техніка заливки UV смоли у форми — один із найпростіших способів створити прикрасу ручної роботи вдома. Ви заливаєте шар смоли у силіконову форму, додаєте глітер або скибочки фімо, фіксуєте під LED лампою за кілька хвилин — і прикраса готова. Завдяки 48 кольорам блискіток можна варіювати дизайн від ніжних пастельних відтінків до яскравих акцентних стилів. З одного набору виходить кілька десятків різних виробів: сережки, кулони, брелоки, підвіски — усе у власному стилі.

Що в комплекті

  • Силіконова форма (1 шт.) — для заливки кулонів, сережок та інших прикрас.
  • Рукавички (1 пара) — захищають руки під час роботи зі смолою.
  • Мірні стаканчики (4 шт.) — для точного дозування епоксидної смоли.
  • UV-лампа (1 шт.) — забезпечує швидку полімеризацію смоли за лічені хвилини.
  • Дерев'яні палички (5 шт.) — для перемішування смоли та розподілу декору.
  • Епоксидна смола (100 мл.) — UV-смола, готова до використання без додаткового змішування.
  • Серветка (1 шт.) — для акуратного прибирання робочого місця.
  • Глітер, паєтки, блискітки (48 кольорів) — широка палітра декору для різноманітних дизайнів.
  • Скибочки фруктів фімо (12 г.) — декоративні елементи для оздоблення прикрас.
  • ПУ-мотузки 40,5 см (3 шт.) — для оформлення кулонів і підвісок.
  • Брелоки (3 шт.) — готові основи для виробів на ключі.
  • Кільця (12 шт.) — з'єднувальні елементи для збирання прикрас.
  • Тримачі кулонів (12 шт.) — фурнітура для готових підвісок.
  • Швензи для сережок (12 шт.) — гачки для зборки сережок.
  • Інструкція (1 шт.) — покроковий посібник для початку роботи.

Для кого цей набір

Підійде дітям від 10 років, підліткам і дорослим, які хочуть опанувати роботу з UV смолою вперше або розширити свій творчий арсенал. Чудовий подарунок на день народження чи свято — і гарний привід зібратися за цікавим заняттям усією сім'єю або з подругами.
